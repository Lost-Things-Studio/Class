# Contributing

Contributions should keep Class small, readable, and easy to embed.

Before opening a pull request:

```bash
luac -p class.lua tests/*.lua
lua tests/run.lua
```

For the full process, see the repository contribution guide:

- [CONTRIBUTING.md](https://github.com/Gopmyc/Class/blob/main/CONTRIBUTING.md)
- [Code of Conduct](https://github.com/Gopmyc/Class/blob/main/CODE_OF_PRODUCT.md)
